# SJB Dixital MultiOverride Plugin

Overrides y ajustes para tu PS 1.7

## Descripción

Este plugin sirve como cajón desastre para añadir overrides y cambios cvarios a tu PS 1.7

## Empezando:

### Dependencias

* Uso basico sin composer hasta el momento.

### Instalando

* Subir a tu PS, y activar. En su pantalla de configuración, activar los overrides que necesites.
